# EchoBar

EchoBar — компактное нативное приложение для macOS, записывающее звук, который воспроизводят другие приложения. Один щелчок начинает запись, второй сохраняет WAV.

![Наклонная композиция из настоящих снимков окна записи и настроек EchoBar](../../docs/assets/echoBar-hero.png)

## Возможности

- **Запись системного звука.** Воспроизведение приложений захватывается через Apple Core Audio. Звук слышен и во время записи. Разрешение на доступ к микрофону не требуется.
- **Небольшое окно записи.** Семиполосный спектр показывает низкие частоты слева, высокие справа. После часа таймер показывает часы, минуты и секунды. Используйте круглую кнопку или **⌘R**.
- **Управление размером файлов.** PCM WAV сохраняется с частотой источника либо с частотой 16, 24, 32, 44,1 или 48 кГц и разрядностью 8, 16 или 24 бита. Настройки показывают примерный размер за час. При меньших значениях файл компактнее, а качество ниже.
- **Удобные настройки.** Закрепляйте окно поверх обычных окон, открывайте папку записей в Finder и меняйте папку, формат и поведение при закрытии в том же окне. Настройки сохраняются локально.
- **Данные остаются на Mac.** Записи, настройки и данные восстановления хранятся локально. Телеметрии, загрузки файлов и сторонних зависимостей нет.
- **13 языков интерфейса.** Выберите язык приложения или используйте настройки macOS. Настройки на арабском отображаются справа налево.
- **Понятная обратная связь.** Настройки открываются со сдвигом в том же окне. После сохранения нажмите на статус, чтобы показать файл в Finder, или включите уведомления macOS.

## Начало записи

1. Соберите и запустите EchoBar. Разрешите захват системного звука, когда macOS запросит доступ.
2. Включите звук в другом приложении и нажмите красную кнопку. Повторное нажатие сохраняет запись. Папка по умолчанию — `~/Music/回聲錄音/`.
3. Значок папки открывает место сохранения, шестерёнка — настройки. Изменения параметров записи действуют со следующей записи.

## Восстановление и совместимость

При обычном выходе EchoBar сначала завершает сохранение. После сбоя или принудительного завершения снова откройте приложение, чтобы восстановить звук, записанный на диск. Последняя часть, оставшаяся только в памяти, может быть потеряна.

Требуется **macOS 14.2 или новее** на совместимом Mac с Intel или Apple silicon. Liquid Glass используется начиная с macOS 26. На более ранних версиях применяются стандартные материалы системы. Сборка включает обе архитектуры. Работа проверена на Apple silicon.

## Сборка из исходного кода

Откройте [EchoBar.xcodeproj](../../EchoBar.xcodeproj) в Xcode с macOS 26 SDK или новее. Выберите схему **EchoBar** и цель **My Mac**, затем нажмите **⌘R**. Универсальная сборка Release:

```sh
xcodebuild -project EchoBar.xcodeproj -scheme EchoBar -configuration Release \
  -destination 'generic/platform=macOS' -derivedDataPath DerivedData build
```

Приложение находится в `DerivedData/Build/Products/Release/EchoBar.app`. Для локальной сборки используется подпись ad hoc.
