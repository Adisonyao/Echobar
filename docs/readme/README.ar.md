# EchoBar

EchoBar مسجّل أصلي صغير لنظام macOS. يلتقط الصوت الذي تشغّله التطبيقات. اضغط مرة لبدء التسجيل ومرة أخرى لحفظ ملف WAV.

![صورتان حقيقيتان لنافذتي التسجيل والإعدادات في EchoBar بتكوين مائل](../../docs/assets/echoBar-hero.png)

## الميزات

- **تسجيل صوت النظام.** يلتقط صوت التطبيقات عبر Core Audio من Apple. يبقى الصوت مسموعًا أثناء التسجيل، ولا يلزم إذن الميكروفون.
- **نافذة صغيرة وسهلة الاستخدام.** يعرض الطيف الحي سبعة نطاقات، من الترددات المنخفضة يسارًا إلى المرتفعة يمينًا. بعد ساعة يظهر المؤقت الساعات والدقائق والثواني. استخدم زر التسجيل الدائري أو **⌘R**.
- **التحكم في حجم الملف.** احفظ بصيغة PCM WAV بمعدل المصدر أو 16 أو 24 أو 32 أو 44.1 أو 48 كيلوهرتز، وبعمق 8 أو 16 أو 24 بت. تعرض الإعدادات الحجم التقريبي لكل ساعة. تؤدي القيم المنخفضة إلى ملفات أصغر وجودة أقل.
- **خيارات تناسب عملك.** ثبّت النافذة فوق النوافذ العادية، وافتح مجلد التسجيل في Finder، وعدّل المجلد والصيغة وسلوك الإغلاق من النافذة نفسها. تُحفظ التفضيلات محليًا.
- **بيانات محلية.** تبقى التسجيلات والتفضيلات ومعلومات الاسترداد على جهاز Mac. لا يتضمن التطبيق أدوات قياس الاستخدام أو رفع الملفات أو تبعيات خارجية.
- **13 لغة للواجهة.** اختر اللغة في التطبيق أو اتبع إعدادات macOS. تُعرض الإعدادات بالعربية من اليمين إلى اليسار.
- **ملاحظات واضحة.** تنتقل الإعدادات داخل النافذة نفسها. بعد الحفظ، اضغط على الحالة لإظهار الملف في Finder أو فعّل إشعارات macOS لتلقي تأكيد الحفظ.

## بدء التسجيل

1. ابنِ EchoBar وشغّله، ثم اسمح بتسجيل صوت النظام عند ظهور طلب macOS.
2. شغّل الصوت في تطبيق آخر واضغط الزر الأحمر. اضغطه مجددًا للحفظ. المجلد الافتراضي هو `~/Music/回聲錄音/`.
3. يفتح رمز المجلد موقع الحفظ، ويفتح رمز الترس الإعدادات. تنطبق إعدادات التسجيل على الجلسة التالية.

## الاسترداد والتوافق

عند الخروج العادي، ينهي EchoBar حفظ التسجيل أولًا. بعد تعطل التطبيق أو إنهائه بالقوة، افتحه لاسترداد الصوت الذي كُتب على القرص. قد يُفقد آخر جزء بقي في الذاكرة فقط.

يتطلب **macOS 14.2 أو أحدث** وجهاز Mac متوافقًا بمعالج Intel أو Apple silicon. يتوفر Liquid Glass بدءًا من macOS 26، وتستخدم الإصدارات السابقة مواد النظام القياسية. يتضمن البناء المعماريتين، واختُبر التشغيل على Apple silicon.

## البناء من المصدر

افتح [EchoBar.xcodeproj](../../EchoBar.xcodeproj) في Xcode المزود بـ macOS 26 SDK أو أحدث. اختر مخطط **EchoBar** ووجهة **My Mac**، واضغط **⌘R**. لبناء Release بالمعماريتين:

```sh
xcodebuild -project EchoBar.xcodeproj -scheme EchoBar -configuration Release \
  -destination 'generic/platform=macOS' -derivedDataPath DerivedData build
```

يوجد التطبيق في `DerivedData/Build/Products/Release/EchoBar.app`. يستخدم البناء المحلي توقيعًا مخصصًا محليًا.
